## 2. Findings (gotchas → all recorded in AGENTS.md / PLAN.md)

### HoloViews
1. **Bare `import holoviews` lies about the backend**: `Store.current_backend` is set
   while `loaded_backends()` is still empty → `.opts()` raises "No plotting extension
   is currently loaded". Test `loaded_backends()`. Both the SDK (script process) and
   preview sizing (app process) bootstrap bokeh themselves because of this.
2. **DynamicMaps don't pickle** — `rasterize()`/`datashade()` output holds local
   closures. SDK materializes them to their current frame. *Accepted limitation:
   rasterized previews are static — pan/zoom work but don't re-aggregate on zoom.*
3. **`.opts()` does not survive pickle** — options live in `Store.custom_options`
   keyed by object id. The SDK captures explicit plot/style/norm kwargs per element
   (`traverse()`-order aligned) and the runner re-applies after unpickle. Symptom if
   forgotten: styling silently ignored, plots render with library defaults (the user's
   first "viridis" was actually the default cmap).
4. **`aspect="equal"` is incompatible with auto-sizing** — bokeh `match_aspect`
   computes the plot area from stale default 600×600 dims under fit policies
   (measured: 494×355 canvas in a 1560×799 figure; `sizing_mode="stretch_both"` no
   better). Skills forbid it until a client-side fix exists.
5. **Opts are lazy** — invalid values pass through the subprocess fine and raise only
   at render time in the app process.

### Panel / bokeh (1.9.3 / 3.9.2)
6. **FastListTemplate wraps each main item in a content-sized fast-card** whose shadow
   slot never gets height → bokeh "fit" policies measure ~40 px parents and figures
   collapse. VanillaTemplate's main propagates height cleanly (measured: full
   viewport). Decision: M2/M3 shell uses VanillaTemplate.
7. **Setting `pane.object` in place while the session document initializes renders
   0-height figures** (timing race: fast scripts finish before page load). Fix:
   recreate the HoloViews pane per figure (`_show_figure`).
8. **Panel 1.9 renders pane content inside Shadow DOM** — page-level diagnostics with
   plain `querySelector` find nothing and wrongly conclude nothing rendered.
   Must traverse `shadowRoot`s. (This misled several debugging rounds.)
9. **A raising periodic callback freezes the whole session** — bokeh disables it.
   `tick()` is exception-guarded; and `queue.Empty` IS an `Exception` subclass —
   catch it explicitly before any broad `except Exception` (first guard attempt
   swallowed Empty into the crash guard and broke every tick).
10. Widgets: `Widget.name` → `label`, `Button.button_type` → `color` (1.7+
    deprecations).

### Scripts & sizing policy
11. **Never set `width=`/`height=` opts in scripts** — explicit sizes beat the
    container-fit sizing → fixed-size half-window plots. The skill template states
    this as a rule.
12. The v1 `fit_container_hook` (opts `hooks=[...]` setting
    `width_policy/height_policy="fit"` on `plot.state`) remains the correct way to
    make figures fill containers; explicit width/height serve as initial hints only.

### Tooling
13. **ruff formats markdown code blocks** — keep examples in .md files ruff-clean.
14. `pkill -f <pattern>` matches the invoking shell's own command line if the pattern
    appears in it — use `fuser -k <port>/tcp` or bracket tricks.
15. **playwright + headless Chromium became the standard UI verification tool**:
    shadow-DOM-aware DOM measurement, bokeh model inspection, canvas pixel sampling
    (proving colormap changes visually), button clicks. Added as a dev dependency.
    Chromium headless shell: `uv run playwright install chromium`.

## 3. Decisions made (this session)

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | Embedded pty terminal for the agent (not SDK chat) | harness-agnostic, works with local models, filesystem-only coupling |
| 2 | Keep HoloViews + Datashader for generated plots | 1–2M-row files; skills compensate for LLM familiarity gap |
| 3 | One active script (`plot.py`) per workspace in v2 | simplicity; multi-script is future work |
| 4 | Subprocess runner + pickle transport, figure returned to app process | never run generated code in the server process |
| 5 | Transport payload = `{figure, options}` — opts captured/re-applied | opts don't pickle (§2.3); discovered via user-visible bug |
| 6 | DynamicMaps materialized to static frames | pickling impossible; re-aggregation-on-zoom = future work |
| 7 | VanillaTemplate shell (not FastListTemplate) | fast-card wrapping breaks fit-sizing chain (§2.6) |
| 8 | Figure panes recreated per run (never in-place `.object=`) | doc-init timing race renders 0-height figures (§2.7) |
| 9 | Preview auto-sizes figures; scripts must not set width/height | explicit sizes beat container-fit; half-window plots (§2.11) |
| 10 | `aspect="equal"` banned in skills for now | breaks auto-sizing (§2.4); tracked as future work |
| 11 | All failures degrade to banners + last-good plot; `tick()` never dies | single bad run must never brick the session |
| 12 | playwright as dev dep; headless pixel-level verification | the only reliable way to debug Shadow-DOM Panel UIs (§2.15) |
| 13 | Demo workspace uses the real 121 MB file, not fixtures | fixtures can be degenerate (single inline: 24 km × 25 m) and misled early debugging |
